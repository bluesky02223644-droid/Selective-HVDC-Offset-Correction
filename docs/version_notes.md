# Version notes

Software v1.0.0 implements manuscript workflow v2.1.

The public copy cleans documentation and descriptive metadata while preserving
numerical criteria, revision selectors and executable scientific logic.
`SOURCE_MANIFEST.json` records original and public-source hashes.

The supplied configuration uses `candidate_audit=True`: candidate evidence is
reported, but the returned observation array remains unchanged and final flags
remain zero. Catalogue edge ends are required; the demo supplies synthetic values.
